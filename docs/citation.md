# Citation

## Software

Cite microvasc with the Zenodo concept DOI
[10.5281/zenodo.23933580](https://doi.org/10.5281/zenodo.23933580), which covers all versions.
The DOI for a single version is on the Zenodo page of that release.

The same metadata is in
[CITATION.cff](https://github.com/helia77/MicroVasc-Review/blob/main/CITATION.cff). GitHub reads
this file for the "Cite this repository" button.

large-scale microvascular networks: a survey. Front. Bioinform. 5:1645520 (2025).
doi: [10.3389/fbinf.2025.1645520](https://doi.org/10.3389/fbinf.2025.1645520)
